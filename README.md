# Hanzi Bloom Plus

Отдельная статическая страница с описанием подписки, тарифами, условиями доступа и контактами.
GitHub Pages: публикация из ветки `main`, корень `/`.

Тарифы: 299 ₽/месяц, 1 990 ₽/год; международные — $5.99/месяц и $39.99/год.
Реальные продажи пока не открыты. До запуска нужно добавить утверждённую оферту,
порядок возврата, публичные реквизиты самозанятой и подключить платёжный сервер.
Страница не собирает данные через формы, не использует аналитику и не принимает оплату.

Для локального просмотра: `python -m http.server 8765 --bind 127.0.0.1`.

Иконка и скриншот взяты из существующего сайта владельца
https://raccoon-app-labs.github.io/apps/hanzi-bloom/.
